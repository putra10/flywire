Inside the experiment +

This is a simplified rate model on a measured FlyWire subgraph, not a validated reconstruction of a living fly. Every neuron updates from its connected inputs. The same dynamics and input are used in both modes.

Connection weights start as synapse counts, then receive population-specific normalization and gains. Acetylcholine is modeled as excitatory; GABA and glutamate as inhibitory. Glutamate’s effect depends on receptors, so its sign here is an assumption. Four cells with unresolved transmitter predictions are excluded.

Turning supplies a moving, modeled heading cue; this demo does not claim to reproduce biological angular-velocity integration. This cue can organize either mode, so center the slider to compare persistence. At rest the cue switches off, and real wiring can drift toward preferred headings. Ring positions are inferred from connectivity, not measured anatomical coordinates. Zero degrees is arbitrary.

Shuffling permutes each neuron’s outgoing destinations, including empty slots. This preserves the exact edge count, outgoing weights, and transmitter sign, while breaking spatial organization. Patch coherence is the circular concentration of EPG activity; it is not biological accuracy.

The 3D ring is a schematic. The anatomy view uses simplified skeletons of these neurons from the published FlyWire v783 reconstruction. Skeleton branches show cell shape, not individual synaptic connections. Activity is assigned per neuron, not simulated separately along each branch. Anatomy stays fixed when wiring is shuffled.
